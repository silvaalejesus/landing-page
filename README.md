# Landing page

Este projeto é uma aplicação web construída com React, TypeScript e Vite, e publicada no [GitHub Pages](https://silvaalejesus.github.io/landing-page/).

## Tecnologias Utilizadas

- React
- TypeScript
- Vite
- GitHub Pages

## Executando Localmente

Para executar o projeto localmente, siga estes passos:

1.  Clone o repositório:

    ```bash
    git clone https://github.com/silvaalejesus/landing-page.git
    ```

2.  Navegue até o diretório do projeto:

    ```bash
    cd landing-page
    ```

3.  Instale as dependências:

    ```bash
    yarn install
    ```

4.  Inicie o servidor de desenvolvimento:

    ```bash
    yarn dev
    ```

5.  Abra o navegador e acesse `http://localhost:5173`.

## Aviso

Os botões neste projeto são estáticos e não possuem ações implementadas.
